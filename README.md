# Sunrays-Effect

**Sunrays-Effect** is a JavaScript-based project that simulates a dynamic sunrays animation effect using particles. When you click anywhere on the canvas, a burst of particles radiates outward, creating a sunrays-like effect. This project demonstrates the use of particle systems to create visually appealing interactive effects.

## Features

- **Interactive Sunrays Effect**: Click anywhere on the canvas to trigger a burst of particles, creating a sunrays effect.
- **Particle System**: Dynamic particles are emitted from the click position, radiating outward.
- **Smooth Animation**: Real-time rendering of particles, creating a fluid and engaging effect.
